## Задание 2.

### Определение границ системы.

### Будет включено в систему:

1. Консольный вывод игрового поля.
2. Ввод хода пользователем через координаты.
3. Проверка возможности хода.
4. Поиск и удаление комбинаций из трёх и более элементов.
5Подсчёт очков игрока.

### Не будет включено в систему:

1. Графический интерфейс.
2. Онлайн-режим.
3. Сохранение игры в файл.
4. Звуки и визуальные эффекты.
5. Искусственный интеллект.

### Главные подсистемы:

1. Подсистема управления игрой.
2. Подсистема игрового поля.
3. Подсистема обработки ходов.
4. Подсистема поиска комбинаций.
5. Подсистема генерации новых элементов.
6. Подсистема подсчёта очков.

### Пользовательские метафоры:

1. Игра — процесс, которым управляет пользователь.
2. Доска — поле 8 на 8, где находятся элементы.
3. Клетка — отдельное место на доске.
4. Ход — попытка поменять два соседних элемента местами.
5. Комбинация — три и более одинаковых элемента подряд.
6. Очки — результат игрока за собранные комбинации.

### Функциональность:

1. Показать текущее поле.
2. Принять координаты двух элементов.
3. Проверить, являются ли элементы соседними и выполнить их обмен.
4. Найти комбинации на поле.
5. Удалить элементы и начислить очки.
6. Заполнить пустые клетки новыми элементами.

### Библиотеки повторного использования:

1. `random` — для генерации новых элементов.
2. Стандартные средства ввода и вывода.
